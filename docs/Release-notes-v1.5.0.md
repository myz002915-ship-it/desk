# GlassDesk 1.5.0

2026-10-24 · 从 1.4.1 升级至 1.5.0：启动更快，程序坞与启动台的悬停反馈重做。

## 启动更快

- 目标失效复查、运行应用首次枚举、启动台预热改为首帧之后执行。以前它们挡在“第一次画出程序坞”前面，条目指向网络路径或已拔出的移动盘时，开屏可能要等上数秒。
- 启动台与设置窗口改为首次使用时才构造。设置窗口此前每次启动都要解析 31 KB 界面、读取注册表与当前用户身份、解码两张收款码图片，而绝大多数会话里它根本不会打开。
- 启动日志新增各阶段耗时，出问题时能直接看出卡在哪一步。

## 程序坞

- 悬停时图标下方出现一层柔和的玻璃高光，三个内置入口（启动台、此电脑、桌面图标）与应用磁贴一起放大、一起亮起，不再只有应用图标有反馈。
- 修复拖放结束后整行磁贴被重建两次的问题：一次成功的拖放此前要重建两遍、图标解码两遍，落点回弹时能看出停顿。
- 图标按“路径 + 修改时间”缓存已解码的位图，替换图标文件后自动失效；拖拽经过时不再为计算插入位置分配整份几何数组。
- 触控板/鼠标横扫过整行时，高光依次亮起又依次熄灭，不会逐帧闪烁。

## 启动台

- 悬停与按下反馈在浅色主题下也能看见。此前这两个状态写死成白色叠加，浅色玻璃上等于没有反馈。
- 悬停时磁贴描边随之亮起，配合放大更接近“图标被托起”的层次感。
- 搜索框空输入时显示“搜索应用”水印；添加按钮、文件夹操作按钮的悬停色一并跟随主题。

## 说明

适用于 Windows 11 x64（Build 22000 及以上），自带 .NET 10 运行时。升级保留设置、应用库、文件夹、布局、自定义图标和登录启动配置。安装包不包含个人 Data；安装包未签名，可用同页 SHA256SUMS.txt 核对。
