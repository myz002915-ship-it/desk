# GlassDesk 1.5.0

2026-10-24 · 从 1.4.1 升级至 1.5.0：启动更快，程序坞与启动台的悬停反馈重做。

## 启动更快

- 目标失效复查、运行应用首次枚举、启动台预热改为首帧之后执行，不再挡在“第一次画出程序坞”前面。
- 启动台与设置窗口改为首次使用时才构造；设置窗口不再在每次启动时解析界面、读取注册表与当前用户身份、解码收款码图片。
- 启动日志新增各阶段耗时。

## 程序坞

- 悬停时图标下方出现柔和的玻璃高光；启动台、此电脑、桌面图标三个内置入口与应用磁贴一起放大、一起亮起。
- 修复拖放结束后整行磁贴被重建两次的问题，落点回弹不再停顿。
- 图标按“路径 + 修改时间”缓存解码结果；拖拽经过时不再分配几何数组。

## 启动台

- 悬停与按下反馈在浅色主题下可见（此前写死成白色叠加）。
- 悬停时磁贴描边亮起；搜索框空输入显示“搜索应用”水印；添加按钮与文件夹操作按钮的悬停色跟随主题。

Windows 11 x64（Build 22000 及以上）专用，自带 .NET 10 运行时。升级保留设置、应用库、文件夹、布局、自定义图标与登录启动配置；安装包不包含个人 Data。安装包未签名，可用同页 SHA256SUMS.txt 核对。
